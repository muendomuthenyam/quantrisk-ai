A production-grade Python financial risk engine and loan analytics tool designed for micro-lenders, SACCOs, and quantitative analysts.

---

## 🌟 Key Features

* **Automated Credit Scoring:** Dynamic Debt-to-Income (DTI) & Loan-to-Value (LTV) risk grading engine.
* **Portfolio Risk Management:** Value-at-Risk (VaR) simulations and stress testing models.
* **Loan Amortization Suite:** Multi-scenario repayment schedules (Reducing Balance, Fixed Rate, Interest-Only).
* **Interactive Dashboard:** Built with Streamlit for real-time visualization and reporting.
